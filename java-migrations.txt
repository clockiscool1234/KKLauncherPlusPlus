The b.a and b.g classes are compatibility wrappers required by the legacy settings navigation. The readable implementations are in settings.AboutSettingsFragment and settings.GeneralSettingsFragment.

The wallpaper picker eS and its observer eX are compiled together from Java while retaining all static accessor signatures referenced by legacy callbacks. This prevents missing-method crashes, including the eS.j(eS) wallpaper-selection accessor. The picker uses a MediaStore sort order without the unsupported SQL LIMIT token and closes its cursor. The app-list class b is compiled from source and filters the launcher's own package from drawer results. BackupManager reads and writes through Android's document picker, includes home-screen and dock entries, and restores launcher data in one provider batch. The source cG controller retains callback accessor signatures used by legacy first-run listeners; migrated Cling retains the animation-listener accessor and uses null-safe workspace-cling handling. These prevent missing-method and first-launch crashes. Cling's focused-item views are guarded when absent from tablet layouts. The migrated cB source restores the `cB.a(cB):cO` compatibility accessor expected by the legacy content observer. AppCustomizationManager applies per-app name/icon overrides from the settings screen, while DefaultWorkspaceSeeder inserts available core apps into unused dock/home-screen slots on first launch. The settings navigation class nl.ndsc.kitkatlauncher.b.s is compiled from source and safely skips removal when the optional Pro-key preference is absent. The Gradle build patches the legacy BubbleTextView and Workspace class-file references from Region.Op.REPLACE to INTERSECT in a generated copy of launcher-legacy.jar.

The remaining recovered Java sources are under app/src/reconstructed/java/ and are not part of the Gradle source set yet. Their names are still partly obfuscated; migrations will proceed incrementally while preserving compatibility with the remaining bytecode. The migrated cB source handles Android 13+ dynamic receiver registration with RECEIVER_NOT_EXPORTED for system broadcasts. Hotseat and nl.ndsc.kitkatlauncher.o retain the exact static method/field signatures used by legacy bytecode.
